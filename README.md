# Alcode Editor

**استوديو المستندات من شركة Alcode** — تطبيق مكتبي لتحرير وتحويل وتنظيم **كل صيغ المستندات**:
PDF و Word و RTF و ODT و Excel و CSV و PowerPoint و EPUB و Markdown و HTML والنصوص والشيفرة والصور.
يعمل بالكامل على جهازك بدون إنترنت وبدون رفع أي ملف إلى أي خادم.

*A desktop studio for editing, converting, compressing and organising every document
format — PDF, Word, Excel, PowerPoint, EPUB and more. Fully offline.*

## ✨ المميزات

### العرض والتصفح
- عارض PDF سريع مبني على pdf.js مع تمرير متصل أو صفحة‑بصفحة.
- **تحديد ونسخ النص مباشرة من الصفحة** عبر طبقة نص شفافة فوق الرسم.
- بحث يُبرز كل تطابق في مكانه داخل الصفحة، مع تنقّل بين النتائج وعدّاد «٣ من ١٢».
- تكبير وتصغير، ملء العرض، ملء الصفحة، حجم فعلي، وتدوير العرض.
- شريط مصغّرات جانبي بتحميل كسول (يفتح مستندات بمئات الصفحات دون تأخير).
- فهرس المستند (Outline) والانتقال المباشر لأي قسم.
- بحث نصي كامل داخل المستند مع مقتطفات ونتائج قابلة للنقر، وبحث عربي مطبَّع
  يتجاهل التشكيل ويطابق «الأسم» بـ«الاسم».

### تنظيم الصفحات
- إعادة الترتيب بالسحب والإفلات، وعكس الترتيب.
- تدوير، حذف، تكرار، واستخراج الصفحات المحددة إلى ملف جديد.
- إدراج صفحة فارغة أو إدراج صفحات من ملف PDF آخر في أي موضع.
- تحديد متعدد مع شريط أدوات يعمل على التحديد مباشرة.

### التحرير والتعليقات
- نص حر، تظليل، رسم يدوي، خطوط، مستطيلات، بيضاوي، صور، و**تنقيح حقيقي**.
- لوح توقيع بالفأرة/اللمس، ووضع التوقيع في أي مكان على الصفحة.
- تحكم كامل في اللون، السماكة، الشفافية، حجم الخط، والتعبئة.
- تحريك وحذف أي عنصر، ثم **دمج التعليقات نهائياً في الملف**.
- تشغيل كامل بلوحة المفاتيح: Enter لإضافة شكل، الأسهم للتحريك، Alt+الأسهم لتغيير الحجم، Delete للحذف.

#### التنقيح: حذف فعلي وليس مربعاً أسود

معظم التطبيقات ترسم مستطيلاً أسود فوق النص وتسمّي ذلك «تنقيحاً» — والنص يبقى كما هو داخل
الملف، ويستخرجه أي قارئ. Alcode Editor يفعل الشيء الحقيقي:

1. يقرأ مجرى محتوى الصفحة ويتتبّع مصفوفات النص والتحويل ومقاييس الخطوط ليحدّد موضع كل كلمة فعلياً.
2. **يحذف** أوامر رسم النص والصور الواقعة داخل المنطقة، ويستبدلها بإزاحة مكافئة حتى لا يتغيّر ترتيب بقية الصفحة.
3. يحذف التعليقات وحقول النماذج المتقاطعة مع المنطقة (فهي تحمل نسخاً من النص لا يمسّها المربع الأسود).
4. يدخل إلى نماذج XObject المشتركة بعد استنساخها، حتى لا يتأثر أي صفحة أخرى.
5. **يتحقّق** بعد الحفظ بإعادة استخراج النص: إن نجا شيء داخل المنطقة تُسطَّح الصفحة إلى صورة،
   ويخبرك التقرير بأي صفحات حدث لها ذلك. فالتطبيق لا يَعِد بما لم يتحقّق منه.

**تنقيح بالبحث:** رسم مربع لكل موضع لا يصلح لرقم هوية يتكرّر في أربعمئة صفحة — وهذه هي الحالة
التي وُجد التنقيح من أجلها. أداة «تنقيح وحذف نهائي» تبحث عن نص أو تعبير نمطي في كل الصفحات،
وفيها أنماط جاهزة (بريد إلكتروني، هاتف، آيبان، هوية وطنية/إقامة، بطاقة ائتمان، تاريخ)،
وتعرض كل تطابق مع ما حوله من كلمات لتراجعه قبل الحذف، ثم تحذف المحدَّد دفعة واحدة.
البحث يتجاهل التشكيل واختلاف الألف والهمزة، ويمكن حفظ تقرير بما حُذف — لأن التنقيح لا رجعة فيه.

### التعرّف الضوئي على النص (OCR) — عربي وإنجليزي، بدون إنترنت

المستند الممسوح ضوئياً هو صورة للنص: لا يُبحث فيه ولا يُنسخ منه. يشغّل التطبيق محرّك
Tesseract بالكامل داخل جهازك — العامل ونواة WebAssembly ونماذج اللغة العربية والإنجليزية
كلها مضمّنة، فلا تُرفع وثيقة سرّية إلى أي خادم لتُقرأ.

- **اجعل الملف قابلاً للبحث:** تُضاف طبقة نص غير مرئية فوق الصورة عند إحداثيات الكلمات
  المكتشفة، فتعمل الكتابة في البحث والتحديد والنسخ بينما يبقى شكل الصفحة كما هو تماماً.
- **استخراج النص:** حفظ ما قُرئ في ملف نصي مرتّب حسب الصفحات.
- اختيار اللغة (عربي، إنجليزي، أو الاثنان) ودقة المسح (200/300/400 DPI) ونطاق الصفحات.
- عند فتح ملف يبدو ممسوحاً ضوئياً ينبّهك التطبيق تلقائياً إلى وجود الأداة.
- الطبقة المضافة تحمل النص العربي بصيغته المنطقية لا بأشكاله المتصلة، فيطابقه البحث المطبَّع.
- دقة العربية تعتمد على جودة المسح ونوع الخط، والتطبيق يقول ذلك صراحةً بدل المبالغة.

### العربية: التفاصيل التي تُفسد المستند بصمت

- **الأرقام العربية‑الهندية لا تنقلب.** مُشكّل الخطوط يصنّف ١٢٣٤٥ نصًّا عربيًا يُقرأ من اليمين،
  فيعكس رقمًا رتّبته خوارزمية الاتجاه ترتيبًا صحيحًا أصلاً — ورقم الهوية يخرج مقلوبًا على
  الصفحة وفي كل مستخرِج نص. التطبيق يعالج ذلك في كل ما يكتبه: أرقام الصفحات، التواريخ،
  المبالغ، وطبقة الـOCR غير المرئية.
- استخراج النص يرتّب أجزاء السطر حسب اتجاهه، فلا تنقلب الجملة العربية عند النسخ أو التحويل.
- «كلمة كاملة» في البحث والاستبدال مبنيّ على حدود يونيكود لا على `\b` الإنجليزية.
- الأرقام العربية‑الهندية داخل خلايا الجداول تُقرأ كأرقام لا كنص.

### قراءة صحيحة للعربية والإنجليزية

الملفات النصية لا تحمل تصريحاً بترميزها، فيكتشفه التطبيق بنفسه:

- علامة الترتيب (BOM) لـ UTF‑8 و UTF‑16 بنوعيها.
- تحقّق صارم من صحة UTF‑8.
- عند الفشل يجرّب **Windows‑1256** و **ISO‑8859‑6** و Windows‑1252 و Windows‑1251
  ويحسب نقاطاً لكل ترميز بحسب كمية الحروف الحقيقية التي ينتجها — فيختار الصحيح.
- تطبيع أشكال الحروف العربية المتصلة (Presentation Forms) القادمة من ملفات PDF و DOC القديمة.
- كشف تلقائي لاتجاه النص من موازنة الحروف القوية.

النتيجة: ملف CSV عربي قديم بترميز Windows‑1256 يُفتح بنص سليم بدل الرموز المشوّهة.

### تصغير حجم الملفات
- **PDF:** سباق بين إعادة بناء بلا فقد وإعادة رسم الصفحات كصور — ويُبقى الأصغر فقط.
- **الصور:** إعادة ترميز عبر canvas مع حدّ لأقصى بُعد، وتجربة JPEG و WebP واختيار الأصغر.
- **ملفات Office (DOCX/XLSX/PPTX/ODT/ODS/EPUB):** فكّ الحزمة، وضغط الصور المضمّنة بداخلها،
  ثم إعادة الحزم بأقصى مستوى deflate.
- في كل الحالات: إن لم ينتج الضغط ملفاً أصغر، يُبقى الأصل كما هو ويُخبرك التطبيق بذلك.

### التصميم والتجربة
- واجهة مستوحاة من لغة تصميم Apple: أسطح شفافة، حدود شعرية، زوايا ناعمة، وحركات نابضة.
- وضع فاتح وداكن وتلقائي يتبع النظام، مع ستة ألوان تمييز.
- عربي كامل بواجهة RTL، وإنجليزي بواجهة LTR — قابل للتبديل فوراً.
- لوحة أوامر (`Ctrl/Cmd + K`) تفتح الأداة نفسها مباشرة، ببحث عربي مطبَّع.
- زر إيقاف على شاشة الانتظار للعمليات الطويلة (التعرّف الضوئي، الضغط بإعادة الرسم).
- تراجع/إعادة على مستوى المستند، وسجل ملفات حديثة.
- شريط عنوان مخصص يتكيّف مع ويندوز وماك.

### الأداء
- العارض المتصل **مُحوسَب افتراضياً**: تُقاس أبعاد الصفحات مرة واحدة لكل مستند ولا تُركّب
  إلا الصفحات القريبة من الشاشة — فملف من 500 صفحة يكلّف بضع لوحات رسم بدل مئات الميغابايتات.
- شبكة الجداول تعرض نافذة الخلايا المرئية فقط، والكتابة تبقى محلية حتى مغادرة الخلية.
- تُقرأ المصنّفات من الخلايا الموجودة فعلاً لا من المستطيل الذي يعلنه الملف.
- تقسيم الحزمة: حجم بدء التشغيل انخفض من 6.8 ميغابايت إلى نحو 1.1 — وتُحمَّل مكتبات كل صيغة
  عند فتح أول ملف منها.

### إمكانية الوصول
- تشغيل كامل بلوحة المفاتيح: لا مصائد تركيز في الجداول ولا في محرّر الشيفرة (Esc ثم Tab للخروج).
- مصغّرات الصفحات أزرار حقيقية، وإعادة الترتيب بـ Alt+الأسهم.
- النوافذ المنبثقة حوارات فعلية بحصر التركيز وإعادته إلى مصدره عند الإغلاق.
- حلقة تركيز مرئية في كل مكان، وتباين ألوان يحقّق مستوى AA.
- احترام تفضيل النظام لتقليل الحركة (`prefers-reduced-motion`) في CSS وفي محرك الحركات معاً.

### سلامة الملفات

الأدوات التي تعيد بناء المستند كانت تفقد أشياء لا يراها المستخدم إلا لاحقًا. الآن:

- **إعادة الترتيب والحذف والاستخراج والتكرار وعكس الترتيب** تُعاد صياغتها على شجرة
  صفحات المستند نفسه بدل نسخ الصفحات إلى ملف فارغ — فتبقى الفهارس (Bookmarks)
  والنماذج والمرفقات وتسميات الصفحات وبنية الوصول كما هي.
- **«تحسين وإصلاح»** يعيد كتابة الملف كاملًا بدل إعادة بنائه، فيكسب نفس التوفير
  دون أن يمحو ما أنشأته أداتان أخريان في التطبيق نفسه.
- **ملف PDF محمي بكلمة مرور** كان تحريره يُنتج ملفًا لا يفتحه التطبيق نفسه مرة أخرى
  («كلمة المرور غير صحيحة») لأن بقايا معالج التشفير كانت تُكتب مع الملف. صار يُنظَّف
  فعليًا، ويُنبَّه المستخدم قبل الحفظ فوق أصل محمي بأن النسخة الجديدة بلا حماية.
- **الملفات النصية** تُحفظ بالترميز الذي جاءت به (Windows‑1256 يبقى Windows‑1256)
  وبنفس نهايات الأسطر، ولا تُحوَّل صامتة إلى UTF‑8.
- **حفظ ملف نصي** كان يدمج كل الأسطر في سطر واحد؛ صار التحويل من HTML إلى نص
  يحافظ على الفقرات والأسطر تمامًا.
- **صفحات HTML** لم تعد تُحفظ فوق أصلها: القارئ يحتفظ بالجسم فقط، فالحفظ كان
  يستبدل صفحة ويب كاملة بقشرة.
- كل عملية كتابة صارت مغلَّفة: انقطاع القرص أو نفاد المساحة يظهر كرسالة واضحة
  بلغة المستخدم بدل أن يمرّ بصمت.
- الدفعات (تقسيم، استخراج صور، تحويل) تعزل كل ملف على حدة، ولا تكتب فوق ملف
  موجود، وتقول «أُنشئ ٤٠ من ٢٠٠ — تعذّر ١٦٠» بدل رسالة عامة واحدة.

### الخصوصية والأمان
كل المعالجة تتم محلياً داخل التطبيق. **لا يوجد أي اتصال شبكي**، وسياسة أمان المحتوى (CSP)
في التطبيق تمنع أي طلب خارجي. ملفاتك لا تغادر جهازك أبداً.

- الواجهة تعمل داخل **صندوق رمل نظام التشغيل** (`sandbox: true`) — وهي العملية التي تحلّل
  كل صيغة ملف واردة، فتُمنح أقل صلاحية ممكنة.
- نافذة توليد PDF من HTML تعمل **بدون جافاسكربت**، داخل جلسة منفصلة تُلغي كل طلب غير محلي،
  وبمهلة زمنية صارمة — فملف HTML خبيث لا يستطيع الاتصال بالخارج ولا تعليق التطبيق.
- الكتابة على القرص مقصورة على المسارات التي وافق عليها المستخدم فعلاً عبر حوار الحفظ
  أو التي فتحها بنفسه.
- كل HTML وارد — بما فيه مخرجات mammoth من ملفات Word — يمرّ عبر DOMPurify عند مصدره،
  ويُجرَّد من كل مرجع خارجي قبل الطباعة.
- **صفر اتصالات شبكية — مُتحقَّق منه:** شُغّلت النسخة المحزومة مع تسجيل كامل لطبقة الشبكة
  (`--log-net-log`) أثناء فتح مستند وتشغيل التعرّف الضوئي على النص، فلم يُسجَّل أي طلب خارجي.
  أُوقفت أيضاً خدمات Chromium الخلفية (تحديث المكوّنات، موثوقية النطاقات، مزامنة الوقت)،
  ووُضع مانع طلبات على مستوى الجلسة يلغي أي طلب `http(s)` مهما كان مصدره.
- **التدقيق الإملائي مغلق افتراضياً:** على ويندوز ولينكس ينزّل Chromium قاموسه من خوادم Google
  أول مرة — وهو الطلب الوحيد الذي كان التطبيق يصدره. صار خياراً صريحاً في الإعدادات يشرح ذلك،
  وعلى macOS يُستخدم مدقّق النظام دون أي تنزيل.

## 🛠 التقنيات

| الطبقة | التقنية |
| --- | --- |
| الغلاف المكتبي | Electron 33 (frameless, contextIsolation, sandbox: true) |
| الواجهة | React 19 · TypeScript · Framer Motion · Zustand · Lucide |
| عرض PDF | pdfjs-dist (worker مُضمّن محلياً) |
| تحرير PDF | @cantoo/pdf-lib (يشمل تشفير AES‑256) |
| Word / RTF / ODT | mammoth · docx · محلّل RTF وODT مكتوب داخل المشروع |
| العربية في PDF | fontkit + bidi-js + خط أميري مضمّن (نص متجهي قابل للبحث) |
| تنقيح المحتوى | محلّل مجرى محتوى PDF مكتوب داخل المشروع + تحقّق بعد الحفظ |
| التعرّف الضوئي | tesseract.js + نواة WebAssembly ونماذج `ara`/`eng` مضمّنة بالكامل |
| الجداول | SheetJS (xlsx, xls, ods, csv) |
| PPTX / EPUB | JSZip + DOMParser (استخراج مباشر من الحزمة) |
| تنقية HTML | DOMPurify — كل مستند وارد يمرّ عبرها قبل عرضه |
| Markdown | محوّل داخلي + Turndown للتصدير |
| توليد PDF من HTML | `webContents.printToPDF` في نافذة Chromium خفية |
| البناء والتغليف | electron-vite · electron-builder (NSIS + DMG) |

**دعم العربية في PDF — نص متجهي حقيقي:** خطوط PDF القياسية الأربعة عشر لا تغطي العربية.
كان التطبيق يرسمها صورةً، فتخرج غير قابلة للبحث ولا للتحديد وتتشوّه عند التكبير. الآن يضمّن
التطبيق مقطعاً من خط **أميري** عبر `fontkit` الذي يطبّق مُشكّل OpenType العربي، ولأن
`fontkit` لا ينفّذ خوارزمية الاتجاه ثنائي الاتجاه (UAX‑9) يُشغَّل `bidi-js` لتقسيم السطر إلى
مقاطع اتجاهية وإعادة ترتيبها قبل الرسم — فيخرج «صفحة 3 من 10» بترتيبه الصحيح.
النتيجة: علامة مائية عربية قابلة للبحث والتحديد وحادّة عند أي تكبير، وبحجم أصغر من الصورة.
النصوص اللاتينية تبقى على الخطوط القياسية فلا يزيد حجم الملف بلا داعٍ.

## 💻 التشغيل من المصدر

```bash
git clone https://github.com/almarar88/liwapdf.git
cd liwapdf
npm install

npm run dev            # تشغيل في وضع التطوير
npm run typecheck      # فحص الأنواع
npm run build          # بناء الحزم
npm run dist:win       # مثبّت ويندوز (يتطلب ويندوز أو wine)
npm run dist:mac       # حزمة macOS (تتطلب macOS)
```
