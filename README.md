يعمل بالكامل على جهازك بدون إنترنت وبدون رفع أي ملف إلى أي خادم.

*A desktop studio for editing, converting and organising PDF & Word documents — fully offline.*

## ✨ المميزات

### العرض والتصفح
- عارض PDF سريع مبني على pdf.js مع تمرير متصل أو صفحة‑بصفحة.
- تكبير وتصغير، ملء العرض، ملء الصفحة، حجم فعلي، وتدوير العرض.
- شريط مصغّرات جانبي بتحميل كسول (يفتح مستندات بمئات الصفحات دون تأخير).
- فهرس المستند (Outline) والانتقال المباشر لأي قسم.
- بحث نصي كامل داخل المستند مع مقتطفات ونتائج قابلة للنقر.

### تنظيم الصفحات
- إعادة الترتيب بالسحب والإفلات، وعكس الترتيب.
- تدوير، حذف، تكرار، واستخراج الصفحات المحددة إلى ملف جديد.
- إدراج صفحة فارغة أو إدراج صفحات من ملف PDF آخر في أي موضع.
- تحديد متعدد مع شريط أدوات يعمل على التحديد مباشرة.

### التحرير والتعليقات
- نص حر، تظليل، رسم يدوي، خطوط، مستطيلات، بيضاوي، صور، وتنقيح (Redact).
- لوح توقيع بالفأرة/اللمس، ووضع التوقيع في أي مكان على الصفحة.
- تحكم كامل في اللون، السماكة، الشفافية، حجم الخط، والتعبئة.
- تحريك وحذف أي عنصر، ثم **دمج التعليقات نهائياً في الملف**.

### صندوق الأدوات (24 أداة)
| الصفحات | التحسين والحماية | المحتوى |
| --- | --- | --- |
| دمج ملفات | ضغط الملف | علامة مائية (نص أو شعار) |
| تقسيم (نطاق/عدد/كل صفحة) | حماية بكلمة مرور AES‑256 | ترقيم الصفحات (أرقام عربية أو لاتينية) |
| تقسيم حسب الحجم | فك الحماية | ترويسة وتذييل |
| استخراج صفحات | تحسين وإصلاح | خلفية الصفحة |
| حذف صفحات | بيانات المستند (Metadata) | ختم جاهز (مسودة/سري/معتمد) |
| تدوير الصفحات | | استخراج الصور المضمّنة |
| دمج صفحات في ورقة (2/4/6/9) | | النماذج: عرض وتعبئة وتسطيح |
| تغيير قياس الصفحة | | مقارنة مستندين سطراً بسطر |
| قص الهوامش | | الفهرس والمرفقات |

### محرر Word
- فتح ملفات `.docx` بتنسيق كامل (عناوين، قوائم، جداول، صور، اقتباسات).
- تحرير غني: عريض/مائل/تسطير/يتوسطه خط، ألوان النص والتمييز، الخط والحجم.
- عناوين ومحاذاة وقوائم نقطية ورقمية واقتباسات.
- إدراج جداول وصور وروابط وخطوط فاصلة وفواصل صفحات.
- بحث واستبدال، تبديل اتجاه النص (RTL/LTR)، عدّاد كلمات وزمن قراءة.
- تصدير إلى **DOCX** و **PDF** و **HTML** و **TXT**.

### التحويل بين الصيغ
`PDF → صور (PNG/JPG بأي دقة)` · `صور → PDF` · `PDF → نص` · `PDF → Word`
`Word → PDF` · `Word → HTML` · `نص/Markdown → PDF` · `HTML → PDF`

### التصميم والتجربة
- واجهة مستوحاة من لغة تصميم Apple: أسطح شفافة، حدود شعرية، زوايا ناعمة، وحركات نابضة.
- وضع فاتح وداكن وتلقائي يتبع النظام، مع ستة ألوان تمييز.
- عربي كامل بواجهة RTL، وإنجليزي بواجهة LTR — قابل للتبديل فوراً.
- لوحة أوامر (`Ctrl/Cmd + K`) للوصول لأي أداة أو شاشة.
- تراجع/إعادة على مستوى المستند، وسجل ملفات حديثة.
- شريط عنوان مخصص يتكيّف مع ويندوز وماك.

### الخصوصية
كل المعالجة تتم محلياً داخل التطبيق. **لا يوجد أي اتصال شبكي**، وسياسة أمان المحتوى (CSP)
في التطبيق تمنع أي طلب خارجي. ملفاتك لا تغادر جهازك أبداً.

## 🛠 التقنيات

| الطبقة | التقنية |
| --- | --- |
| الغلاف المكتبي | Electron 33 (frameless, contextIsolation, sandboxed renderer) |
| الواجهة | React 19 · TypeScript · Framer Motion · Zustand · Lucide |
| عرض PDF | pdfjs-dist (worker مُضمّن محلياً) |
| تحرير PDF | @cantoo/pdf-lib (يشمل تشفير AES‑256) |
| Word | mammoth (قراءة) · docx (كتابة) |
| توليد PDF من HTML | `webContents.printToPDF` في نافذة Chromium خفية |
| البناء والتغليف | electron-vite · electron-builder (NSIS + DMG) |

**دعم العربية في PDF:** خطوط PDF القياسية لا تدعم الحروف العربية. يكتشف التطبيق النصوص
غير اللاتينية ويرسمها عبر محرك النصوص في Chromium بدقة 4× ثم يضمّنها كصورة PNG شفافة —
وهذا يعطي تشكيلاً واتصالاً صحيحاً للحروف دون شحن أي مكتبة تشكيل.

## 💻 التشغيل من المصدر

```bash
git clone https://github.com/almarar88/liwapdf.git
cd liwapdf
npm install

npm run dev            # تشغيل في وضع التطوير
npm run typecheck      # فحص الأنواع
npm run build          # بناء الحزم
npm run dist:win       # مثبّت ويندوز (يتطلب ويندوز أو wine)
npm run dist:mac       # حزمة macOS (تتطلب macOS)
```

### إصدار نسخة جديدة

الملفات التنفيذية تُبنى تلقائياً على GitHub Actions لويندوز وماك:

```bash
git tag v1.0.0
git push origin v1.0.0
```

سير العمل في `.github/workflows/release.yml` يبني النسختين وينشرهما في Release واحد
مع الروابط المباشرة أعلاه. يمكن تشغيله يدوياً أيضاً من تبويب **Actions → Build & Release → Run workflow**.
